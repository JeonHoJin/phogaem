# 사용자 흐름

2026-11-05 사용자 흐름과 현재 구현 기준. 모든 화면은 [DESIGN.md](../DESIGN.md)의 안내 문구 0개 원칙을 따른다. 아래 설명은 개발·설계용이며 제품 화면에 표시하지 않는다.

## 화면 순서

| 진입 | 이동 | 도착 |
| --- | --- | --- |
| 첫 방문 | 명시적 로그인 → 필요한 계정 승인 | 보관함 목록 |
| 재방문 | 기존 계정 세션 복원 → 승인 확인 | 보관함 목록 / 접근 가능한 기존 여행 |
| 초대 링크 | 여행 맥락 보존 → 로그인 → 승인 → 자동 참여 | 초대받은 여행 |
| 보관함 목록 | 만들기 → 이름 입력 → 생성 | 빈 여행 보관함 |
| 여행 보관함 | 사진 선택 → 업로드 | 사진 격자와 파일별 결과 |
| 사진 격자 | 필터 → 선택 → 다운로드 → 명시적 수령 확인 | 개인별 받은 기록 |
| 사진 격자 | 사진 열기 → 전체 화면 / 슬라이드쇼 | 감상 화면 |

첫 방문에는 계정 생성이나 패스키 창을 자동 실행하지 않는다. 승인된 계정과 여행 멤버십을 각각 확인한다. 로그인 성공이나 초대 링크 소지만으로 사진 접근을 허용하지 않는다.

## 만드는 사람

보관함 목록에서 **새 보관함**을 선택하고 이름을 입력한다. 새 보관함으로 바로 이동하며 사진 올리기와 초대 동작을 제공한다. 초대는 공유 시트 또는 링크 복사로 전달한다. 복사 성공은 아이콘 상태로 표시한다. 사진 선택 후 업로드 진행과 성공/실패를 파일별로 표시하고, 성공한 사진은 격자에 나타난다. 중복 원본은 하나로 모으고 참여자 기록을 보존한다.

## 초대받은 사람

링크의 여행 맥락을 로그인과 승인 대기 동안 유지한다. 필요한 경우 잠금 상태에서 계정 코드·승인 재확인·계정 전환 동작을 제공한다. 승인된 계정으로 접속하면 초대받은 보관함에 자동 참여하고 이동한다. 초대 코드를 다시 입력하게 하지 않는다. 초대가 만료되면 참여 불가 상태에서 나가기 또는 다른 링크 입력으로 복구한다.

## 필요한 사진 가져가기

보관함에서 내 사진 제외·받은 사진 제외 필터를 조합한다. 사진 터치는 크게 보기이고 선택은 별도 동작이다. 선택 중에는 개수·용량과 다운로드 동작을 가까이 표시한다. 일괄 다운로드는 한 파일이면 원본, 여러 파일이면 ZIP으로 가져간다. ZIP 원본 합계는 최대 256MiB이며 개수·용량과 선택 해제 동작을 제공한다. 개별 원본 다운로드도 유지한다.

요청된 사진과 수령 확인된 사진은 별도 상태로 표시한다. 실제 수령 여부는 사용자가 명시적으로 바꾸며 되돌릴 수 있다. 요청 시작·미리보기·전송 완료만으로 수령을 확정하지 않는다. 취소·실패 시 선택과 재시도 경로를 남긴다.

## 함께 감상하기

격자에서 사진을 열고 전체 화면 또는 슬라이드쇼를 선택한다. 사진 비율과 원본을 유지한다. 이동·재생·닫기 동작은 터치와 키보드로 접근 가능해야 한다. 사진 위 설명·슬로건·조작 안내는 표시하지 않는다.

## 중단과 복구

실패·대기 상황도 별도 안내 문구를 만들지 않는다. 상태별 표현은 DESIGN.md의 Interaction states 표를 따른다. 실제 후속 행동이 없는 재시도, 무한 로딩, 단순히 숨긴 오류는 허용하지 않는다. 계정 승인 취소 시 보호된 화면을 비우며 초대 링크로 우회하지 않는다. 플랫폼 소유 인증/파일 창의 문구는 앱이 제거할 수 있는 대상으로 취급하지 않는다.

## 구현과 확인

1. 로그인·보관함 목록·초대 목적지를 연결하고 개발용 로컬/샘플 진입을 보조 위치로 옮긴다.
2. 모든 일반/예외 화면에서 설명·토스트·툴팁을 제거하고 상태·행동 기반 복구로 대체한다.
3. 선택 다운로드를 한 동작으로 묶는 방식을 검증·구현한다.
4. 휴대폰 업로드·필터·선택, PC/큰 화면 감상과 오류 복구를 실제 화면에서 검증한다.

기존 보안·인증·원본 보존 테스트를 유지하면서 사용자 행동과 결과를 검증한다. 문구를 삭제했다는 사실만으로 사용 흐름 완료로 판정하지 않는다. 현재 구현은 공유보관함 중심 진입·로그인·초대 목적지 보존·상태별 직접 조작·ZIP 다운로드를 포함한다. 자동 테스트와 화면 검토 후 Pages 배포로 반영한다.

## 보관함 이동과 초대

보관함 안의 **보관함 목록**은 목록으로 돌아가고, 선택 상자는 다른 보관함으로 이동한다. **친구 초대**는 현재 보관함의 링크와 공유·복사만 표시한다. 보관함 주인만 초대할 수 있다. **보관함 설정**은 현재 멤버와 내 닉네임을 다루고, 상단의 **계정**은 로그인 수단과 기기 보관함을 다룬다. 새로 만들기·초대 참여 입력·친구 초대·설정을 한 창에 섞지 않는다. 자동 업로드는 범위에서 제외한다.
