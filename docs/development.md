# 로컬 개발

## 명령

레포 루트에서 Node.js 22.18 이상과 npm을 사용한다.

```sh
npm ci
npm run dev
```

접속 주소: http://127.0.0.1:5173/phogaem/

```sh
npm test
npm run typecheck
npm run lint
npm run build
npm run test:e2e
```

로컬 Chrome이 있으면 브라우저 테스트에 사용한다. 없는 환경은 먼저 `npx playwright install chromium`을 실행한다. 브라우저 테스트가 개발 서버를 자동으로 띄우며, 실패 시 추적과 스크린샷은 Git에서 제외된 `test-results/`에 남긴다.

정적 빌드 산출물은 `dist/`, 로컬 미리보기는 `npm run preview`다. 빌드는 배포를 수행하지 않는다.

## 현재 기능

- 브라우저 IndexedDB에 원본 Blob과 메타데이터 저장.
- SHA-256 + 파일 크기로 완전 동일 파일 통합. 동일 파일의 이름이 달라도 하나로 모으며 업로더와 업로드 횟수는 보존.
- 모든 사진, 친구 사진만, 내가 올린 사진, 아직 안 받은 사진, 중복 업로드 필터의 AND 조합.
- 선택한 원본의 개별 다운로드, 요청 기록, 수령 확인, 기록 되돌리기.
- 키보드 이동·Escape·전체 화면·4초 간격 슬라이드쇼 뷰어.
- 합성 일러스트 12장과 미리보기 사용자 4명으로 로컬 시나리오 체험.

## 제한과 저장 범위

기본 기기 보관함은 브라우저 하나의 로컬 데이터다. 별도로 연결하는 서버 공유 모드는 [통합 안내](integration.md)를 따른다. 앱을 열 때 mlhops나 Cloudflare에 연결하지 않는다. API 키·R2 설정이 없어도 모든 개발·테스트가 가능하다.

파일당 최대 50MiB다. 비어 있는 파일·미지원 형식·사용자 SVG 업로드는 거절한다. 업로드 묶음에 잘못된 파일이 섞이면 전체를 저장하지 않는다. 브라우저가 표시하지 못하는 HEIC 등도 원본은 저장하며 미리보기 대신 안내를 표시한다. 촬영시각 추출·이미지 변환은 아직 없다.

‘아직 안 받은 사진’은 사용자가 ‘받았음 확인’을 하지 않은 사진이다. 브라우저가 실제 디스크 저장 성공을 보장하지 않으므로 다운로드 요청만으로 필터에서 제외하지 않는다. 한 번에 전체 원본을 메모리 ZIP으로 만들지 않고 파일별 다운로드 버튼을 제공한다.

이 앱은 서비스 워커를 설치하지 않는다. 페이지가 열린 상태에서 로컬 기능은 네트워크 없이 동작하지만, 오프라인 상태에서 첫 접속·새로고침까지 보장하지는 않는다.

사이트 데이터 삭제·브라우저 자동 정리·시크릿 모드 종료 시 로컬 보관함이 사라질 수 있다. 실제 원본의 유일한 보관처로 사용하지 않는다. 공유 모드의 계정 연결은 구현되었으며 원본 수명 정책은 후속 단계에서 확정한다.

## 의존성

런타임은 React와 React DOM이며, 빌드·타입 검사·린트·브라우저 테스트 도구만 개발 의존성으로 둔다. `minimatch`는 하위 린트 도구 의존성의 알려진 glob 패턴 취약점 때문에 11.0.1 이상으로 override했다. 업데이트 시 `npm audit`, 린트·빌드·테스트를 함께 검증한다.
